# Factory Reallocation & Shipping Optimization Recommendation System for Nassau Candy Distributor

## Project Overview
This project develops a data-driven Factory Reallocation and Shipping Optimization Recommendation System for Nassau Candy Distributor. The system analyzes historical shipment data and evaluates alternative factory allocation scenarios across Product, Destination Region, and Ship Mode combinations. The goal is to identify factory reassignment scenarios that may improve shipping lead-time performance while considering scenario reliability and profitability-related risk.

## Project Objectives
- Analyze historical shipping and operational performance.
- Evaluate factory-to-region and factory-to-shipping-mode relationships.
- Simulate alternative factory allocation scenarios.
- Estimate potential lead-time improvements.
- Checking scenario reliability and profitability risk.
- Rank factory reassignment opportunities using a composite recommendation score.
- Provide an interactive Streamlit decision-support dashboard.

## Analytical Workflow
The project follows these major stages:
1. Data Cleaning and Validation
2. Feature Engineering
3. Route Definition and Aggregation
4. Factory–Region–Ship Mode Analysis
5. Scenario Simulation
6. Lead-Time Improvement Evaluation
7. Profitability Risk Assessment

9. Recommendation Classification

## Streamlit Dashboard
The Streamlit dashboard converts the analytical and scenario-based results into an interactive decision-support interface. The dashboard includes:
- KPI Summary
- Factory Optimization Simulator
- Recommendation Dashboard
- Product, Region, Ship Mode and Recommendation Status filters
- Risk and Impact Analysis
- Optimization Priority Analysis
- Executive Decision Summary
- What-If Scenario Analysis

Users can compare current and recommended factory assignments and idetify expected lead-time improvement, recommendation score, scenario reliability, profitability risk, and recommendation status.

## Important Note
The recommendations generated by this project are analytical decision-support outputs based on historical shipment data and simulated factory-reallocation scenarios. They should not be interpreted as guaranteed operational outcomes.
Actual implementation would need additional validation of factory capacity, inventory availability, transportation costs, carrier arrangements, production constraints, and other operational factors that are not fully represented in the source dataset.
